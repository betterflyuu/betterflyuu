# Betterflyuu Momma Shop — Emerald Flow

Responsive Robux top-up landing page for Betterflyuu Momma Shop.

## Current behavior
- Emerald/teal animated gradient with a CSS butterfly mascot.
- WhatsApp buttons and WhatsApp scripts removed.
- All order/contact calls-to-action go directly to Discord: https://discord.gg/xsttwG5kZv
- Robux calculator is disabled for now; no slider, nominal input, quick-pick controls, or order-choice modal.
- Responsive layout for mobile, tablet, and desktop.

## Files
- `index.html` — page structure
- `style.css` — Emerald Flow visual theme and responsive layout
- `script.js` — mobile navigation and footer year

## Deploy
Replace these three files in the existing GitHub repository connected to Vercel. Keep the repository's existing assets/folders if there are any. Vercel should redeploy automatically after the commit.
