# Betterflyuu Momma Shop — Emerald Flow V3

Responsive static website for Betterflyuu with an interactive Robux calculator (10–2,000 Robux, increments of 10), automatic pricing at Rp153 per Robux, and WhatsApp/Discord order choice.

## Theme update
- Deep emerald/teal palette inspired by the supplied green typography reference.
- Condensed Anton headings and Dancing Script accent, with DM Sans body text.
- Flowing animated green gradients while preserving the existing butterfly mascot animation and page layout.

## Files
- `index.html` — page structure and Google Fonts.
- `style.css` — responsive layout, theme, animation, and components.
- `script.js` — calculator and order-choice behavior.

## Deploy
Replace the corresponding three website files in the existing GitHub repository (`index.html`, `style.css`, `script.js`) and commit. Keep existing image/assets folders. Vercel should deploy automatically when connected to that repository.

Do not commit API tokens, Discord bot secrets, or `.env` files.
