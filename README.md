# Betterflyuu Momma Shop — Website

Minimalist Robux storefront for Betterflyuu Momma Shop. Existing visual theme is preserved.

## Robux calculator
- Slider and manual numeric input from 10 to 2,000 Robux.
- Values move in steps of 10 Robux.
- Price is calculated automatically at Rp153 per Robux.
- Quick picks: 100, 500, 1,000, and 2,000 Robux.
- Order choice modal routes to WhatsApp or Discord.

## Files
- `index.html` — page structure and order choice modal
- `style.css` — responsive styling, calculator, and modal
- `script.js` — calculator math and order interactions

## Deploy
Upload/replace these three files in the existing GitHub repository connected to Vercel. No backend is required for the calculator.
