## Deploy ke Vercel
1. Upload/push semua file ini ke repository GitHub.
2. Buka Vercel dan import repository.
3. Framework Preset: Other / Static.
4. Deploy.

Catatan: harga dan nomor WhatsApp bisa diubah langsung dari `script.js`.
